# navbike · 电动车通勤选路 App

一个只为自己做的电动车导航 App：20 km 通勤，**少红绿灯、优先大路、右转免等灯**。

市面上的导航给电动车只算一条路线，你没法比较、也没法把自己的偏好喂进去。这个 App 的想法很简单——**路线本身改不了，但可以给路线打分，并且把「你的偏好」变成可以调的权重**。

iOS + Expo + React Native，纯客户端，不需要服务器。

---

## 它解决什么问题

高德的电动车路径规划接口（`v5/direction/electrobike`）有两个硬限制：

1. **一次只返回一条路线**，没有备选方案；
2. **不返回红绿灯数量**，也不支持策略参数（不像驾车接口能选"少收费""避免拥堵"）。

所以「哪个路线更适合我」这件事，官方接口不回答。这个 App 的做法是：

- 把返回的路线拆成一段段 `steps`，逐段分析；
- 用一个**可调权重的评分模型**给出 0–100 分；
- 你也可以记录「我自己实际怎么走」，两条路线并排对比，看差在哪里。

分数不是绝对的真理，只是让"我觉得这条更好"变成一个能看见的数字。

## 功能

**选路与打分**

- 起点 / 终点 / 中间点输入，带高德输入提示（inputtips）联想
- 中间点通过**分段算路**实现（起点→中间点→终点拼接），因为接口本身不支持 waypoints
- 百分制评分，三个维度加权：

  | 维度 | 看什么 | 默认权重 |
  |---|---|---|
  | 时间 | 全程平均速度 | 45% |
  | 转向 | 左转扣分、右转加分 | 35% |
  | 道路 | 大路占比加分、小路占比扣分 | 20% |

- 权重在界面上可调（±5% 微调，自动归一化，存本地，改完即时生效不用重算）

**对比**

- 「对比我的走法」：把你实际走的路线也输进去，两条并排打分，给出分差

**保存**

- 历史记录（最多 50 条）、常用路线（最多 8 条，同名覆盖）

**导航**

- 全屏导航：定位跟随、车头向上 / 北向上可切换
- 罗盘驱动朝向：站着不动只转手机，地图也会跟着转
- 中文语音播报：距路口 300 / 100 / 30 米各播一次，同一句不重复
- 偏航检测：连续 3 次偏离超过 60 米才提示，避免 GPS 漂移误报
- 偏航后重新规划，**自动跳过已经走过的中间点**，不会让你掉头回去
- 已走路段变灰、剩余路段蓝色
- 双指捏合缩放、单指拖动，手动操作后镜头让开 2 秒再自动跟回

## 技术栈

- Expo SDK 58 / React Native / TypeScript
- `react-native-maps`（iOS 上用 Apple Maps，中国大陆底图数据来自高德）
- `expo-location`（定位 + 罗盘）、`expo-speech`（中文播报）、`expo-keep-awake`（导航时常亮）
- `@react-native-async-storage/async-storage`（历史 / 常用 / 权重）
- 高德 Web 服务 API：`v3/geocode`、`v3/assistant/inputtips`、`v5/direction/electrobike`

## 目录结构

```
App.tsx              主界面：输入、算路、评分卡片、历史、权重面板
src/
  config.ts          读取 EXPO_PUBLIC_AMAP_KEY
  AddrInput.tsx      带联想候选的地址输入框（500ms 防抖）
  score.ts           评分模型：analyze / roadKind / normalize / grade
  guide.ts           把 steps 摊平成连续路线，做定位吸附与剩余里程计算
  Nav.tsx            全屏导航界面
  store.ts           AsyncStorage 读写封装
```

## 自己跑起来

**1. 申请高德 Key**

去 [高德开放平台控制台](https://console.amap.com/dev/key/app) 创建应用，添加 Key 时**服务平台选「Web服务」**（不是 iOS/Android 平台）。个人开发者免费额度足够日常使用。

**2. 配置 Key**

```bash
cp .env.example .env
```

然后编辑 `.env`，填入你的 Key：

```
EXPO_PUBLIC_AMAP_KEY=你的Key
```

`.env` 已被 `.gitignore` 忽略，不会被提交。Expo 会在打包时把 `EXPO_PUBLIC_` 开头的变量内联进 JS 包。

**3. 安装依赖并启动**

```bash
npm install
npx expo start --go
```

手机装 Expo Go，扫码即可运行。装了原生模块（location / speech / maps）需要用 `--go` 走 Expo Go 内置版本，不需要自己编译。

## 打包成独立 App（不付 $99）

Apple 开发者账号 $99/年，个人自用没必要。可行路径是**自己编译一个未签名 ipa，再用免费 Apple ID 签名安装**：

1. 仓库已带 `.github/workflows/ios-unsigned.yml`：在 Actions 里手动触发，云端 macOS 机器会产出未签名的 `navbike-unsigned.ipa`
2. 电脑装 iTunes（Apple 官网版）+ [Sideloadly](https://sideloadly.io/)
3. 插线，把 ipa 拖进 Sideloadly，填自己的 Apple ID，点 Start
4. 手机上信任开发者证书 + 开启开发者模式

代价：免费签名 **7 天过期**，到期要插线重签一次（数据不会丢）。同时最多 3 个自签 App。

> 用 GitHub Actions 打包需要在仓库 Settings → Secrets and variables → Actions 里加一个 `AMAP_KEY`，值是你的高德 Key。工作流会在编译前把它注入环境，公开仓库的日志里不会出现明文。

## 已知限制

- **只有一条路线**：高德电动车接口不返回备选方案，所以这个 App 不能"选路"，只能"评估一条路"并让你对比自己的走法
- **没有红绿灯数据**：接口不返回，转向和道路分是靠路名与转向类型推断的，不等于真实路口情况
- **评分是启发式的**：`score.ts` 里的阈值（均速 12→30 km/h 映射、左转扣 8 分等）是拍出来的，不一定符合你的体感，欢迎按自己的经验改
- **历史分数是当时的**：历史记录存的是保存时权重算出的分数，之后调权重不会回溯重算
